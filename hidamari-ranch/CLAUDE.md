# CLAUDE.md — ひだまり牧場(このフォルダ)で作業するときのルール

ほのぼの系の競走馬育成ゲーム。牧場運営・馬の育成・レース。ひとりで長く遊べるように作っている。
持ち主はプログラミング初心者。**説明は日本語で、専門用語には短い説明を付ける。**
同じリポジトリの BLACK HARBOR(リポジトリ直下のファイル)とは別のゲーム。おたがいのファイルを参照・変更しない。

## 持ち主の環境(重要)

- 持ち主のパソコンには Node.js が入っていない。ローカル実行や `npm install` を前提にしない
- 公開手順:GitHub → Render(Web Service、Root Directory = `hidamari-ranch`)。手順は README.md。手順が変わったら README も直す

## 約束

1. **ビルドツールを入れない。** 素の HTML / CSS / JavaScript(ES modules)
2. Three.js 0.170.0 は CDN(jsdelivr)から import map で読み込む。3D が読み込めなくても絵地図・2D レースで遊べるようにしておく
3. サーバーは Express で静的ファイルを配るだけ。秘密情報・環境変数は使わない(`PORT` のみ)
4. セーブはブラウザの localStorage(`hidamari-save-auto` / `hidamari-save-1〜3`)。サーバーには保存しない
5. 実在の団体・レース・馬・商品の名前やロゴは使わない(レース名・馬名・人名はすべて架空)

## 更新するときの決まり(重要)

- JS を変えたら **版の番号を1つ上げる**:すべての `?v=数字`(index.html と js/*.js の import)と、
  `game.js` / `main.js` の `BUILD` を同じ数字にそろえる。古いファイルと新しいファイルが混ざるのを防ぐため
  (過去の不具合:更新直後、ブラウザに残った古い game.js と新しい main.js が混ざり、レースのボタンでエラー)
- サーバーは `Cache-Control: no-cache` で配る(毎回、更新を確認させる)

## しくみ

- ルールの計算は `public/js/game.js` だけに書く(画面のコードを入れない。node で直接テストできるように)
- データ(レース・関係者・会話・施設)は `public/js/data.js`
- お金の単位は「万円」。1年 = 48週(1か月 = 4週)。ゲームは1年目4月(13週目)から。最初から3歳馬がいて、すぐレースに出られる
- 2歳馬のデビューは21週目(6月)から
- レースは seed つきで同じ結果を再計算できる(`runRace`)。スパートを押すと、そこから先だけ変わる。画面で見たレースの結果を `advanceWeek(s, { raceResults })` に渡す
- 毎週の「作業」を増やさない:お世話は1頭週1回の「ふれあう」だけ(まとめてもOK)。仲よくなる主な道は、週のおわりの「えらべるできごと」(data.js の CHOICE_EVENTS)
- 古いセーブデータでも読めるように、項目を増やしたら `validate()` で足りない値を補う
