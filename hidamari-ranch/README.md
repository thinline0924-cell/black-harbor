# ひだまり牧場 — ちいさな競走馬ものがたり

ほのぼの系の競走馬育成ゲームです。小さな牧場をうけついで、馬を育て、レースに挑み、
次の世代へとつないでいきます。ブラウザだけで遊べます。

- **箱庭の牧場(ローポリの3D)**:浮かぶ島のような牧場。まわりには畑・川・村・森・山なみ・遠くの競馬場・浮かぶ小島・気球が広がります。季節で色が変わり(春は桜、冬は雪)、
  馬たちが放牧地を歩いたり、調教コースを走ったりします。建物をクリックすると、その場所でできることが開きます
- **絵地図**:「V」キーまたは右下の「表示切替」で、パズルのような絵地図に切り替え(3D が使えない端末でも遊べます)
- **馬の育成**:5つの能力(スピード・スタミナ・パワー・根性・賢さ)、調子、疲れ、性格、成長タイプ(早熟・普通・晩成)、
  得意な距離と芝/ダート、脚質(逃げ・先行・差し・追込)。「おまかせ」にすると毎週のメニューを自動で決めてくれます
- **絆(きずな)**:「ふれあう」(1頭につき週1回、全員まとめてもOK)で馬との絆が深まります。やらなくても少しずつ深まります。
  騎手と馬の絆も、いっしょに走るたびに深まります
- **できごと**:週のおわりにときどき、なかまや馬との小さなできごとが起きます。えらんだ答えで、なかよし度や馬の様子が変わります
- **なかま(関係者)**:厩務員・調教師・獣医・騎手3人・となりの子・ライバル馬主。おはなし・差し入れで「なかよし度」が上がり、
  助けてくれることが増えます。なかよし度 20・50・80 で、それぞれの小さな物語が見られます
- **レース**:作戦(逃げ・先行・差し・追込)をえらんで、3D の競馬場で実況つきのレース。最後の直線で「💨 スパート!」を
  いいタイミングで押すと伸びます(早すぎるとバテる)。新馬戦から G1 まで、架空の重賞が1年に27
- **牧場の運営**:厩舎の拡張、調教コース、坂路、プール、診療所、風車小屋、ひだまりの丘。セリで1歳馬を買ったり、
  繁殖牝馬セールに行ったり
- **世代をつなぐ**:引退した牝馬は繁殖牝馬に、重賞を勝った牡馬は種牡馬に。春に種付けすると次の年に子馬が生まれ、名前をつけられます
- **長く遊べる**:目標(16個)、トロフィー棚、年度のまとめ、思い出アルバム、お金や勝利数のグラフ、引退馬の記録
- **BGM と効果音**:ブラウザの中で合成しています(音のファイルを使っていないので権利の心配がありません)

## 公開のしかた(Render)

パソコンに何かを入れる必要はありません。ブラウザだけでできます。

### 1. GitHub にファイルがあることを確認

このフォルダ(`hidamari-ranch`)の中に、`server.js` `package.json` と `public/` フォルダが入っていれば準備OKです。

### 2. Render で公開する(Web Service として作る)

1. https://dashboard.render.com を開いてログイン
2. 右上の **New +** → **Web Service** を選ぶ
3. リポジトリの一覧から、このフォルダが入っているリポジトリを選んで **Connect**
   - 一覧に出てこないときは **Configure account**(GitHub の設定)を押して、Render がそのリポジトリを読めるように許可してください
4. 設定画面で、次のように入力します

   | 項目 | 入れるもの |
   | --- | --- |
   | Name | `hidamari-ranch`(好きな名前でOK。アドレスの一部になります) |
   | Branch | このフォルダが入っているブランチ(ふつうは `main`) |
   | **Root Directory** | `hidamari-ranch` ← **大事**。「このフォルダの中がアプリです」という意味 |
   | Runtime(Language) | `Node` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | `Free` |

5. (あれば)**Advanced** を開いて **Health Check Path** に `/healthz` と入れる(なくても動きます)
6. **Create Web Service**(または **Deploy Web Service**)を押す
7. 数分待って、表示されたアドレス(例:`https://hidamari-ranch-xxxx.onrender.com`)を開けば完成です

**入力する設定(環境変数)はありません。** APIキーも合言葉も使いません。

> 別のやり方:Render の **New + → Blueprint** で、Blueprint のファイルの場所(Blueprint Path)に
> `hidamari-ranch/render.yaml` を指定しても公開できます。

### 注意

- Render の無料プランは、しばらく誰も使わないとサーバーが眠ります。次に開くとき、起きるまで1分ほどかかります
- **セーブデータは、遊んでいる人のブラウザの中に保存されます**(サーバーには保存しません)。
  なので、サーバーが眠ったり再起動したりしても、セーブは消えません
- 別のパソコンやスマホで続きを遊びたいときは、「システム」タブの **「セーブデータを書き出す」** でコードをコピーし、
  別の端末のタイトル画面 **「セーブデータを読む」** にはりつけてください
- ブラウザの履歴やサイトデータを消すと、セーブも消えます。大事なデータはコードを書き出してメモしておくと安心です

## 遊び方のあらまし

1. **マップ**の建物をクリック(3D はドラッグで回せます、ホイール/ピンチで拡大)
2. **調教コース**で今週のメニューを決める(迷ったら「おまかせ」)
3. 右下の **「🏁 レース」** ボタン(地図の「レース事務所」でも同じ)→ ①走る馬をえらぶ → ②レースのカードの「このレースに出る」を押す
   (8週先までのレースは予約もできます。2歳馬のデビューは6月から)
4. 右下の **「1週すすめる」**(キーボードなら Space)→ 作戦をえらぶ → レース開始。最後の直線で **「💨 スパート!」**(Space)
5. 気が向いたら**厩舎**で「ふれあう」。春には**繁殖場**で種付け。週のおわりの「できごと」で、なかまと仲よくなれます
6. 右上の **「!」** に、いまの目標とヒントが出ます

キーボード:Q / E でタブ切り替え、R でレース、V で表示切替、Esc で閉じる、Space で1週すすめる、1〜5 でタブを直接えらぶ

## ファイルのしくみ

| ファイル | 中身 |
| --- | --- |
| `server.js` | 画面のファイルを配るだけのサーバー(Express) |
| `public/index.html` `public/style.css` | 画面の骨組みと見た目 |
| `public/js/data.js` | レース・関係者・会話・施設などのデータ(名前はすべて架空) |
| `public/js/game.js` | ゲームのルールの計算(調教・レース・繁殖・お金など) |
| `public/js/main.js` | 画面の操作(タブ・パネル・会話・レースの再生・セーブ) |
| `public/js/ranch3d.js` `models.js` | 箱庭の牧場(3D)と、ローポリの馬・木・建物 |
| `public/js/race3d.js` `race2d.js` `racepath.js` | レースの画面(3D と、3D が使えないときの 2D) |
| `public/js/art.js` `charts.js` | 馬の横顔・似顔絵・絵地図・グラフ(SVG) |
| `public/js/audio.js` | BGM と効果音(その場で合成) |
