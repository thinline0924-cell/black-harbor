# BLACK HARBOR — 闇ブローカーたちの狂宴

港湾都市「ブラック・ハーバー」で、闇ブローカーとして密輸を競う対戦ボードゲームです。
ルールブックを少しわかりやすくして、ブラウザで遊べるようにしました。

- **チュートリアル**:絵つきの説明 → CPU と練習ゲーム(フェーズごとにコーチが説明)
- **CPUと対戦**:CPU 1〜3人と対戦(途中でやめても「つづきから」で再開できる)
- **オンライン対戦**:部屋コードで友達と2〜4人。空いた席には CPU を入れられる
- **3D の盤**:自分のトラック(駒)をつかんでルートに置く。検問ではサイコロが3Dで転がる
- **グラフ**:突破確率、警戒度の出やすさ、資産の推移、成績表など

## 公開のしかた(Render)

パソコンに何かを入れる必要はありません。ブラウザだけでできます。

### 1. GitHub にこのリポジトリがあることを確認

このリポジトリ(`black-harbor`)に、`server.js` `package.json` `render.yaml` と `public/` フォルダが入っていれば準備OKです。

### 2. Render で公開する

1. https://dashboard.render.com を開いてログイン
2. 右上の **New +** → **Blueprint** を選ぶ
   (Blueprint = `render.yaml` という設計図を読んで、自動で設定してくれる機能)
3. リポジトリの一覧から **black-harbor** を選んで **Connect**
   - 一覧に出てこないときは、**Configure account**(GitHub の設定)を押して、
     Render が `black-harbor` を読めるように許可してください
4. 内容を確認して **Apply**(または **Deploy Blueprint**)を押す
5. 数分待って、表示されたアドレス(例:`https://black-harbor-xxxx.onrender.com`)を開けば完成です

**入力する設定(環境変数)はありません。** APIキーも合言葉も使いません。

### 友達と遊ぶ

1. タイトルで「オンライン対戦」→ 名前を入れて「部屋を作る」
2. 表示された **5文字の部屋コード**(または「コピー」したリンク)を友達に送る
3. 友達は同じアドレスを開いて「オンライン対戦」→ コードを入れて「部屋に入る」(リンクならコードは自動で入る)
4. 部屋を作った人が「ゲーム開始」

### 注意

- Render の無料プランは、しばらく誰も使わないとサーバーが眠ります。次に開くとき、起きるまで1分ほどかかります
- 部屋はサーバーのメモリ(一時的な記憶)に置いているので、**サーバーが眠ったり再起動したりすると部屋は消えます**。
  そのときは部屋を作り直してください
- 2時間なにもしない部屋は自動で片づけます
- 同じブラウザなら、ページを再読み込みしても同じ部屋・同じ席に戻れます
- CPU対戦はブラウザの中だけで動くので、サーバーが眠っても続きから遊べます

## ルールのあらまし

全5ラウンドで、最も多くの「綺麗な資産(VP)」を持っていた人の勝ち。1ラウンドの流れ:

1. **仕入れ**:市場で貨物・パーツ・協力者を買う(1ラウンド3枚まで)
2. **積載**:運ぶ貨物とルートを全員同時に決めて公開
3. **工作**:工作カード(タレコミ+3・安全通行−3 など)を好きなルートに裏向きで仕掛ける
4. **運搬**:検問の判定。`最終警戒度 = 荷物の警戒度 + 工作カード + ダイス` が上限以下なら突破、超えたら摘発
5. **洗浄**:現金を VP に変える(100万円 = 1VP、1回1000万円まで)

くわしくはゲームの中の「ルールブック」にあります(原作からの変更点も書いてあります)。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `server.js` | サーバー本体。画面のファイルを配る・回数制限 |
| `online.js` | オンライン対戦の部屋(`/api/bh/...`) |
| `public/index.html` `style.css` | 画面の骨組みと見た目(ゲーム機のメニュー風) |
| `public/js/engine.js` | ルールの計算と CPU の考え方(ブラウザとサーバーの両方で使う) |
| `public/js/board3d.js` | 3D の盤・トラックの駒・サイコロ(Three.js) |
| `public/js/main.js` | 画面の操作と進行、CPU対戦/オンライン対戦のつなぎ |
| `public/js/charts.js` | グラフ |
| `public/js/content.js` | ルールブック・チュートリアルの文章 |
| `public/js/fx.js` | 画面切り替えの演出と効果音 |
| `render.yaml` | Render 用の設計図 |
| `package.json` | 使う部品(Express)と起動方法 |
| `CLAUDE.md` | Claude Code が作業するときのルール |
